# 1.0.0rc1 candidate notes

This is a prepared release note, not a published version. RC creation remains blocked by
two external partner records, independent security review, and explicit approval.

The intended candidate freezes the root and supported namespace API, schema head
`0005_webhook_retention`, component revisions, CLI/environment contract, evidence schema, and
deprecation policy. It includes core PostgreSQL effects, in-process handlers, webhooks,
Taskiq handoffs, command idempotency, delegation/FastMCP, conformance, operational
telemetry, migration/backup/retention tooling, compatibility CI, SBOM, and provenance.

Explicit exclusions are non-PostgreSQL persistence, sync APIs, async psycopg, workflow
orchestration, new broker adapters, automatic Taskiq handoff retention, and exactly-once
external-effect claims. Any public API/schema change after RC resets observation.
